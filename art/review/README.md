# Art review workspace

This directory contains only candidates awaiting an explicit approval decision.
Approved, rejected, and superseded raster candidates do not remain here.

Lifecycle:

1. Generate a versioned candidate under `<style>/<subject>/`.
2. Review it at full size and at website thumbnail size.
3. On approval, promote it to the subject's canonical master.
4. Update the subject content or creature pose registry and master hash.
5. Regenerate and validate website derivatives.
6. Remove the review copy after confirming it matches the canonical master.

Do not treat anything in this directory as a production source.
