# More Naturalistic Creature Candidate Set

This directory is an art-only candidate set for all creature profiles in Fantasy Crux. It is intentionally not wired into the website.

## Style lock

Illustrated fantasy realism: believable anatomy with only subtle cartoon-like shape design; four to six broad value shapes; matte opaque gouache brushwork; natural soft modeling with crisp focal edges and selected lost edges; restrained grouped material texture without photographic microdetail. Mature hand-painted illustration, neither photorealistic nor glossy.

The four calibration images in `../../calibration/revision-01/more-naturalistic/` were supplied to every generation as style-only references:

- `warrior.png` for human anatomy and worn materials
- `bear.png` for organic forms and fur
- `dragon.png` for fantastic anatomy and scales
- `village.png` for environments

The generation prompt explicitly prohibited copying their subjects, poses, compositions, palettes, lighting, weather, or mood.

## Production rules

- One principal creature per square image.
- Full readable anatomy and correct limb plan.
- Profile description, Size, Strength, Dexterity, Intelligence, Charisma, armor, movement, attacks, and abilities inform the visual brief.
- Poses and camera angles are deliberately varied; bipedal creatures are not defaulted to an upright hero stance.
- No text, logo, watermark, border, unrelated powers, or incidental fire.
- Website assets and creature content were not changed.

## Fixed interpretations for variable profiles

- `elemental.png`: a large stone elemental.
- `holy-steed.png` and `holy-warrior.png`: servants of a road-and-protection deity; the steed is a sacred iron horse.
- `passion.png`: fear is the embodied passion.
- `guardian.png`: bound to an old bronze burial mask.

`manifest.json` maps every authoritative creature profile to its image and records the current source characteristics plus the visual pose brief.
