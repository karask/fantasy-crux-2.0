# Historical art provenance

This archive preserves text-only prompts, generation records, hashes, review
notes, comparison pages, and superseded process documentation.

Paths recorded inside archived JSON or Markdown are immutable historical output
records. They are not live dependencies and the referenced raster files are
intentionally absent. Active code, manifests, tests, and website templates must
resolve artwork exclusively through `art/library/` and `src/assets/images/`.

No PNG or WebP files belong in this archive.
