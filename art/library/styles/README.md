# Rendering systems

Each subfolder is a reusable, subject-independent rendering system. `STYLE.md`
is the canonical prompt brief and `anchor.png` is its single visual rendering
reference. Vivid Ink remains the only active and published image set.

Preserved rendering briefs:

- `inked-adventure-comic-vivid` (active website style)
- `more-naturalistic`
- `watercolor-storybook`
- `cinematic-graphic-novel`
- `animated-fantasy-feature`

When recreating a style, inherit only brushwork, edge handling, shape
simplification, detail density, color construction, surface behavior, and
material rendering. Content, pose, camera, layout, palette, lighting, weather,
and mood always come from the subject brief.

Inactive anchors are reference-only and must never be copied into website
assets unless that style is explicitly commissioned and approved.
