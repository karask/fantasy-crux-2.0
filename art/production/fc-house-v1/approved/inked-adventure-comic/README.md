# FC-HOUSE-V1: Inked Adventure Comic

This is the locked production illustration style for Fantasy Crux.

## Immutable rendering block

Hand-inked Western fantasy adventure comic: expressive variable-weight brush
contours, simplified believable anatomy, bold silhouette design, flat opaque
colors, two or three hard-edged shadow shapes, sparse dry-brush texture, and
selective line detail at faces and focal materials. Mature, handmade, and
readable; no painterly blending, no glossy 3D.

## Reference roles

1. Use `style-anchor.png` for rendering language only.
2. Add the closest subject-scale anchor for material and detail handling.
3. Add a content or identity reference only when the new asset needs one.
4. Do not inherit objects, composition, palette, lighting, weather, or mood
   from a style reference unless the new asset explicitly asks for them.

The exploration, calibration, and finalist directories remain intact as
reference records. Only the selected masters were promoted here.
