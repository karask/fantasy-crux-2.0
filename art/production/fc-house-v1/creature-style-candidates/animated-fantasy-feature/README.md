# Animated Fantasy Feature creature set

Art-only candidate set for all 57 Fantasy Crux creature entries. Nothing in this
directory is integrated into the website.

## Style lock

Polished hand-drawn fantasy feature-animation cartoon. Clean tapered dark-colored
contours with confident curves and selective internal lines; smoothly sculpted
believable anatomy with restrained appealing exaggeration—slightly emphasized
heads, hands, paws, and expressions, never chibi or childish. Three-to-five clean
color and value shapes with crisp cel boundaries and very limited soft painted
occlusion only where forms overlap. Broad simplified material shapes, readable
silhouettes, expressive posing, high detail at faces and creature heads, medium
detail on bodies, and sparse atmospheric backgrounds.

## Color lock

Vivid natural local colors with controlled complementary accents. Palette,
lighting, weather, and mood follow each creature and its scene rather than being
copied from the style anchor.

## Reference policy

- Content reference: the matching image in `../more-naturalistic/`, used for
  creature identity, current description and statistics, visible abilities,
  anatomy, pose, proportions, temperament, camera, and environmental action.
- Style reference:
  `../../exploration-04/animated-fantasy-feature/anchor.png`, used only for
  contour language, shape design, clean cel construction, edge hierarchy, detail
  density, and simplified material rendering.
- `bear.png` and `dragon.png` reuse the already approved full-size Animated
  Fantasy Feature sentinels. All other creatures use the same two-reference
  production method.

## QA

Each image was checked against the current creature metadata and the naturalistic
content blueprint. Anatomy-sensitive species were inspected for exact limb plans
and nonliteral spirits were checked for their specific identities. Giant Ant and
Wyvern were rejected and regenerated before acceptance. The set preserves the
previous varied action and camera design rather than reverting bipeds to one pose.
