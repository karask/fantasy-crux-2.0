# Skills / Get Things Done

Add points from the **Practical** pool. Every chosen Craft trade is a separate skill.

## Practical skills

| Skill        | Base      | Use it to...                                      |
| ------------ | --------- | ------------------------------------------------- |
| Athletics    | DEX + STR | Balance, climb, jump, swim and exert force.       |
| Craft (type) | INT + 10  | Make and repair goods in your trade.              |
| Deception    | DEX + INT | Sneak, disguise, misdirect or pick pockets.       |
| Driving      | DEX + INT | Handle carts, wagons and similar vehicles.        |
| Healing      | INT + 10  | Treat injuries, stabilise and perform Surgery.    |
| Influence    | CHA + 10  | Persuade, bargain, command or intimidate.         |
| Mechanisms   | DEX + INT | Work with locks, traps, devices and large works. |
| Perception   | INT + POW | Notice details, hidden things and danger.         |
| Performance  | CHA + 10  | Act, speak, sing, dance or play music.            |
| Riding       | DEX + POW | Control a mount in difficult conditions.          |
| Sailing      | DEX + INT | Operate a boat or ship under oar or sail.         |
| Streetwise   | CHA + POW | Find rumours, contacts, illicit goods and routes. |
| Trade        | INT + 10  | Appraise value and negotiate a sale.              |

## Use the right skill, not every skill

Describe what you try; the GM chooses the relevant test. Routine work with
time and tools often needs no roll. Helping and opposed tests: {{ref:modifiers}}.
