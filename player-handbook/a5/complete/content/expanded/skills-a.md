# Skills / Fight & Know

**Start with the base, then add allocated points.** General skills are available
even if you spend no points on them.

## Resistances and combat

| Skill          | Base      | Use it to...                                 |
| -------------- | --------- | -------------------------------------------- |
| Dodge          | DEX + 10  | Evade a perceived attack or physical hazard. |
| Persistence    | POW + 10  | Resist fear, coercion and mental magic.      |
| Resilience     | CON + POW | Endure bodily harm, fatigue and afflictions. |
| Close Combat   | DEX + STR | Attack and Parry with melee weapons/shields. |
| Ranged Combat  | DEX + INT | Shoot or throw at a distance.                |
| Unarmed Combat | DEX + STR | Punch, kick, grapple; Parry unarmed blows.   |

## Knowledge

| Skill            | Base      | Use it to...                                      |
| ---------------- | --------- | ------------------------------------------------- |
| Culture (own)    | INT + 10  | Recall your society's history and customs.        |
| Culture (other)  | INT       | Understand another named society.                 |
| Language (own)   | INT + 50  | Speak your native language.                       |
| Language (other) | INT       | Communicate in another named language.            |
| Lore (own field) | INT + 10  | Know your chosen field of study.                  |
| Lore (other)     | INT       | Know another named field.                         |
| Natural Lore     | INT + 10  | Track, navigate, find food and understand nature. |
| Shaping          | INT + POW | Cast magic; **requires the 20 IP Talent**.        |

Choose **one own Lore field**, such as Alchemy or Military Tactics. Each Culture,
Language and Lore subject is separate. **Language 50%** gives fluent everyday speech.

## Editorial notes

One skill or distinct subject category per table row; no paired skills.
