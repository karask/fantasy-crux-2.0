# Move, Sense & Learn

The cell chooses the method. Wings, a force lift and a stone stair can solve
the same problem without using the same targets, defences or consequences.

## Grant a capability

| Capability                | Benchmark                                                                                                                                                      |
| ------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| New movement mode         | **I2:** climb/swim or traverse a named surface at normal Movement. **I3:** fly at normal Movement.                                                             |
| Pass through matter       | **I4:** one named mundane substance, half Movement; finish each Movement Action in empty space or return to entry.                                             |
| Increase one mode's speed | **I1: +3 m; I2: ×1.5; I3: ×2; I4: ×3.** Separate from buying the mode.                                                                                         |
| Sense                     | **I1:** Low-Light Sight. **I2:** Night Vision or narrow environmental sense. **I3:** Blind Sight with named blocker. **I4:** broad sense of one defined class. |
| Breathing                 | **I1:** hold breath 10 minutes. **I2:** breathe one named medium. **I3:** no need to breathe.                                                                  |

Use your own **Movement Action** for a granted mode; the Shaper need not spend
an Action maintaining a passive benefit. Dangerous movement can still need
Athletics. If flight ends unsupported, you fall. Breathing water gives neither
swimming nor protection from pressure, heat or contact hazards.

## Scry: information, not certainty

**I1:** immediate clue/presence. **I2:** locate, diagnose, communicate or see
through ordinary concealment. **I3:** distant observation, surface thoughts,
deeply hidden evidence. **I4:** guarded memory, history, motives or possible futures.

Live observation, communication and thought-reading require **concentration**;
static facts and fixed senses do not. Scry cannot reveal evidence absent from
accessible minds, places or traces. Senses use Perception when noticing is uncertain.
Use only the best relevant sense; blockers and the Form's scope remain.

## Editorial notes

Speed is calculated magically first, then mundane reductions apply as in the main rules.
