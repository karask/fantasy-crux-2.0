# Forms & Techniques

**Technique + Form = cell.** Learn each of the sixty possible cells separately.
The method must fit both halves.

## The Form: what you affect

| Form         | Governs                                                         |
| ------------ | --------------------------------------------------------------- |
| Fire         | Flame, heat and light.                                          |
| Water/Ice    | Water, cold and ice.                                            |
| Air/Storm    | Air, wind, sound, weather and lightning.                        |
| Earth/Stone  | Soil, stone and natural minerals; not all worked metal.         |
| Flesh        | Biology: living/dead bodies, plants, corporeal undead.          |
| Mind         | Thought, emotion, memory and perception; not Mindless subjects. |
| Force/Motion | Kinetic force, movement, weight and mass.                       |
| Spirit       | Souls, Spirits and possession; not Soulless targets.            |
| Paths        | Routes, thresholds and distance; not time travel.               |
| Fate         | Unresolved chance, omens, vows and contingencies.               |

## The Technique: what you do

| Technique | Permission                                                       |
| --------- | ---------------------------------------------------------------- |
| Conjure   | Create matter, phenomena, routes or beings; no arrival strike.   |
| Bend      | Move, direct or control what exists; no direct damage.           |
| Unmake    | Harm, destroy, suppress, sever or banish.                        |
| Alter     | Heal, transform or impose conditions; no direct damage.          |
| Ward      | Protect, resist or deny; no absolute immunity below I5.          |
| Scry      | Information, communication or senses; do not change the subject. |

**Only Dispel ends an active Shaping.** Intelligent undead have minds, but all
undead are Soulless. Flesh can affect corporeal undead; Spirit cannot.

## Editorial notes

The two axes replace a redundant 60-name grid without removing any cell choice.
