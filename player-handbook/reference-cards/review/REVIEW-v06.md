# Reference cards v06: October 2026 rulings

16 October 2026. Brings the core cards in line with the plain-English website
rules and the rulings made during that rewrite. No other rule changes.

## Changes

- **Card 2:** Withdraw keeps your base Reaction and any off-hand Reaction.
  Intimidate now says what winning does: the GM decides how the enemy gives way;
  the wounded might flee or surrender, the healthy more often hesitate and lose
  a turn. Higher ground reads "Your attack or defence +1B", since position
  modifiers apply to that character's own roll. Delay and Set Weapon were
  shortened to keep the column within the page.
- **Card 3:** the defence table and its notes use the rules' term **Active
  Guard** instead of "guard", and define it as a Parry against a ranged attack.
  The extra off-hand Parry can be an Active Guard, with both penalties applying.
  The damage-order note now reads "Minimum 0; halves round up".
- **All cards:** permission "may" is now "can", as in the website rules.

## Verification

- Three portrait A4 pages, body text 10 pt and table text 9.5 pt; no clipping or
  overflow. Footer clearances: **8.35, 6.78 and 7.05 mm**.
- All three final PDF pages rasterised and visually inspected.
- PDF text compared with v05: only the changes above differ.
- The Downloads entry in `src/_data/downloads.mjs` now selects v06; the site
  build copies it to the stable download URL.

Publication approval is given by merging the pull request that carries this
version. Versions v01-v05 are retained as superseded snapshots.
