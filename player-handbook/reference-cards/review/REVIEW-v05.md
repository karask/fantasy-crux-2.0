# Reference cards v05: paid grapple defence

Card 2 now makes the initial Dodge or Parry cost one eligible Reaction, with
normal defence limits on card 3. An undefended attempt still requires an
Unarmed Combat success. The holder's roll to oppose escape remains free.
The reminder was condensed to retain the existing font size and three-page layout.
