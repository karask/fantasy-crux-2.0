# Shaping reference cards v05

16 October 2026. Brings the cards in line with the plain-English website rules
and the rulings made during that rewrite. No other rule changes.

## Changes

- **Card 2:** "shield guard" is now **shield Active Guard**, the rules' term,
  throughout the defence table, the Counter note and Harm, cover and shields.
  A winning shield Active Guard one Size smaller blocks half the damage,
  **rounded up**. Weapons cannot Active Guard magical projections.
- **Card 3:** Dispel is opposed by a **fresh Shaping roll for the original
  caster**, not the stored casting roll; if their skill is unknown, use 10 × the
  target's M, maximum 100%. Completed permanent changes cannot be Dispelled.
  Permission "may" is now "can".
- **Card 1** is unchanged.

## Verification

- Rendered with the bundled Chromium; no clipped or overflowing text, minimum
  type 9.5 pt. Footer gaps: **6.68, 8.00 and 6.42 mm**, as in v04.
- `verify.py v05`: three A4 pages with complete selectable text, embedded fonts
  and one footer number each.
- All three pages rasterised and visually inspected.
- PDF text compared with v04: only the changes above differ.
